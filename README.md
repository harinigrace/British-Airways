# British Airways Review Dashboard | Tableau

## Project Overview

Customer reviews play a significant role in understanding passenger experiences and improving airline services. In this project, I developed an interactive Tableau dashboard to analyze British Airways customer review data and transform raw feedback into meaningful business insights.

The dashboard enables users to explore customer satisfaction across different service categories, aircraft models, countries, traveller types, seat classes, and time periods. By interacting with filters and dynamic metric selection, users can easily identify trends and compare performance across multiple dimensions.

One of the key highlights of this project is the implementation of **Parameters** and **Calculated Fields**, allowing users to switch between different review metrics without creating multiple visualizations.

## Project Objective

The objective of this project is to analyze customer review data to understand passenger satisfaction and identify factors influencing the overall travel experience. The dashboard helps users compare ratings across different dimensions and supports data-driven decision-making for improving airline services.

## Business Questions Answered

- Which countries have the highest customer satisfaction?
- Which aircraft models receive better passenger ratings?
- How have customer ratings changed over time?
- Does passenger satisfaction vary by traveller type or seat class?
- Which service categories require the most improvement?

## Dashboard Features

### Interactive World Map
Displays average customer ratings by country, helping identify regions with higher or lower passenger satisfaction.

### Rating Trend Analysis
Shows how customer ratings have changed over time, making it easier to identify improvements or declines in service quality.

### Aircraft Performance Analysis
Compares average customer ratings across different aircraft models to determine which aircraft provide better passenger experiences.

### Seat Type Analysis
Analyzes passenger ratings based on seat class, allowing comparison between Economy, Premium Economy, Business, and First Class experiences.

### Traveller Type Analysis
Compares customer satisfaction among different traveller groups such as Business Travellers, Solo Leisure, Couples, and Families.

### Dynamic Metric Selection
Users can interactively switch between different review metrics including:

- Overall Rating
- Cabin Staff Service
- Seat Comfort
- Food & Beverages
- Entertainment
- Ground Service
- Value for Money

This functionality is implemented using **Tableau Parameters** and **Calculated Fields**, eliminating the need to create multiple charts.

### Interactive Filters
The dashboard includes filters for:

- Month
- Traveller Type
- Seat Class
- Aircraft Group
- Continent

These filters allow users to explore specific customer segments and perform detailed analysis.
